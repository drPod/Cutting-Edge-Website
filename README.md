# Cutting Edge

Landing page for Cutting Edge — a local lawn-mowing business. Home, team, services, pricing, hiring, contact. Bootstrap on the Crystal template, customized for the business, deployed to Vercel.

## Run

Static site, no build. Open `index.html` or serve the directory:

```bash
python3 -m http.server
```

Live at [cutting-edge-website.vercel.app](https://cutting-edge-website.vercel.app).
